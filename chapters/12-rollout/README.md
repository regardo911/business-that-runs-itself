# Chapter 12: the calendar

Print `30-day-calendar.md` or copy it onto a whiteboard. Write a real start date, then dates for each week. Block two or three hours a week for it, like a client appointment.

The order matters more than the speed. Stretch it to sixty days if you need to; keep foundation, then money, then growth, then guardrails.

The book's checkpoint for the whole rollout: "You have a dated, week-by-week plan with a specific workflow and a specific deliverable assigned to each of the next four weeks, and week one has a real start date you've committed to."
