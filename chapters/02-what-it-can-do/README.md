# Chapter 2: the scorecard

Ten minutes, no install. Print `scorecard.md` or copy it into a note, write your surface on the first line (for almost everyone: Cowork), and fill both columns with your own business. Keep it somewhere you'll see it; you add to it as you go through the book.

Bookmark the plugin's own folder: `anthropics/knowledge-work-plugins` on GitHub, folder `small-business`. It changed after the book printed; [BOOK-FIXES.md](../../BOOK-FIXES.md) lists what.

## Done when

The book's checkpoint, with today's count in brackets: you can say out loud, to a skeptical friend, "It's [32 skills, 11 workflows and a router], it runs in the Cowork desktop app, it costs twenty dollars a month, and it interfaces with my tools without replacing my accountant."
