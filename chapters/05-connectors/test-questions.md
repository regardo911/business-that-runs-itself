# A test question for every connector

Find the row for the tool you're wiring in, ask the question in Cowork, and check the answer against the real screen.

| Connector | Test question | What to verify |
|---|---|---|
| QuickBooks | "Show my most recent invoice with the customer, amount, date, and status." | Match it in QuickBooks |
| PayPal | "Show my last three payments with payer, amount, and date." | Match PayPal activity |
| Stripe / Square | "Show my last three card payments." | Match the dashboard |
| Gmail | "Show my last two customer emails." | Match the inbox |
| Google Calendar | "What's my next appointment tomorrow?" | Match the calendar |
| HubSpot | "Show my five newest open leads." | Match the CRM |
| Canva | "List my three most recent designs." | Match Canva's home screen |
| Google Drive | "Show the last three files in [folder]." | Match the Drive folder |
| Slack | "Show the last three messages in [channel]." | Match the Slack channel |
| DocuSign | "Show my three most recent envelopes and their status." | Match the envelopes in DocuSign |
